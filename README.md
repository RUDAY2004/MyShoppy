# 🛍️ MyShoppy

A modern mobile shopping application developed using **React Native (Expo)** and **JSON Server**. The application provides a seamless shopping experience by allowing users to browse products, search and filter items, manage their shopping cart, and place orders through an intuitive user interface.

---

## 📌 Project Overview

MyShoppy is a cross-platform mobile shopping application designed to simulate a real-world e-commerce experience. The application demonstrates core mobile application development concepts including state management, API integration, local data persistence, navigation, and responsive UI design.

## 🚀 Installation & Setup

### Clone the Repository

```bash
git clone https://github.com/RUDAY2004/MyShoppy.git
```

### Navigate to Project

```bash
cd MyShoppy
```

### Install Dependencies

```bash
npm install
```

### Start JSON Server

```bash
npm run server
```

### Start Expo Development Server

```bash
npx expo start
```

### Run the Application

- Install **Expo Go** on your Android device.
- Connect both laptop and mobile device to the same Wi-Fi network.
- Scan the QR code displayed in the terminal.
